# SEIR code

This directory contains the activity-aware SEIR engine, calibration utility, and scripts that generate the paper's policy-calendar metrics and Figure 15 when the required local inputs are supplied.

## Scripts

- `seir_timeseries.py`: simulate activity-aware SEIR trajectories.
- `calibration/auto_calibrate_seir.py`: calibrate hazard parameters against a local official epidemic curve.
- `analysis/run_10_seed_table9.py`: run the ten-seed policy comparison and write Table 9 outputs.
- `analysis/plot_figure12_10seed.py`: produce the original-format policy comparison figure.

## Required local files

The scripts require local daily-share inputs, feature metadata, hazard parameters, policy calendars, seed lists, and (for calibration) an HTML epidemic curve readable by `pandas.read_html`. No results or input files are bundled in this repository.

The calibration script's message about `official_curve.html` means exactly this: the archived official curve is an external input, not a result generated by the code. Supply it locally or pass `--official_curve_html`; otherwise calibration cannot run. This does not imply that the file is missing from a packaged result, because packaged results are deliberately excluded from this code-only release.

All output directories should be outside the repository or covered by `.gitignore`.
