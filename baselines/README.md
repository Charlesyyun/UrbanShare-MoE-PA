# Baseline implementations

This directory contains lightweight baseline model implementations and the evaluation protocol used to compare daily activity-share prediction methods. It contains source code and compact protocol metadata only; private training data, checkpoints, and generated agent-level predictions are excluded.

The baseline code is supplementary to the paper's main UrbanShare-MoE-PA pipeline. Use `PAPER_ALIGNMENT.md` and the root `docs/PAPER_ALIGNMENT.md` to distinguish supplementary experiments from the main reported results.
